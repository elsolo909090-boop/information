# Collector Island — обучающая игра (MVP)

Изометрический остров с сундуками-заданиями. Верный ответ → сундук открывается,
+1 рубль, шанс 20% на самоцвет. Есть ежедневный квест, питомец (яйцо → малыш →
взрослый), магазин построек (drag & drop по острову), настройки класса/предметов
и родительский экран со статистикой.

Технологии: **Phaser 3** (HTML5/JS) — работает в браузере на компьютере и
телефоне, легко упаковывается в PWA/WebView. Реклама и трекинг отсутствуют,
весь прогресс хранится локально в `localStorage`.

## Арт

Остров, сундуки и питомец нарисованы по референсам, присланным заказчиком
(`assets/original/*.png`, без изменений/перерисовки). Для использования в
игре из спрайт-листов вырезаны отдельные кадры (`assets/sprites/`):
- `chest_closed.png` / `chest_open.png` — состояния сундука;
- `pet_egg.png` / `pet_baby.png` / `pet_adult.png` — 3 стадии питомца;
- `fox_celebrate.png` — анимация лисы при верном ответе.

Вырезка — чисто техническая операция (обрезка кадра из листа + замена
фейкового шахматного фона на реальную прозрачность), художественное
содержимое не менялось.

## Запуск для тестирования

Нужен Node.js (для локального сервера) **или** любой другой статический
сервер — открыть `index.html` напрямую через `file://` не получится, так как
браузер блокирует `fetch()` базы заданий из JSON без сервера.

```bash
cd collector-island
npm start
# откроется сервер на http://localhost:8080
```

Затем откройте `http://localhost:8080` в браузере (десктоп или мобильный —
интерфейс адаптивный).

Если Node.js недоступен, подойдёт любой другой способ поднять статический
сервер в этой папке, например:

```bash
python3 -m http.server 8080
```

## Как это соответствует ТЗ

- **Остров с 5 сундуками** — `IslandScene.js`, изометрическая сетка.
- **Тап по сундуку → задание** — `onChestTap` открывает `TaskModal` с
  вопросом, вариантами ответа (или полем ввода, если вариантов нет).
- **Верный ответ** — сундук открывается, +1₽, 20%-й шанс на самоцвет
  (`handleResolved` в `IslandScene.js`).
- **Неверный ответ** — показывается подсказка (`TaskBank.hint`), попытка
  без ограничений и без штрафа.
- **Ежедневный квест** — 5 сундуков считаются в `GameState.dailyQuest`,
  прогресс-бар в HUD, тема дня фиксируется по первому решённому предмету и
  сбрасывается на новый день.
- **Питомцы** — покупка яйца за 5💎 в магазине, кормление — каждый решённый
  сундук кормит активного питомца, 3 стадии роста по числу кормлений.
- **Постройки** — покупка за самоцветы в магазине, размещаются на острове и
  их можно перетаскивать (Phaser drag & drop).
- **Настройки** — чекбоксы класса (1–4) и мультивыбор предметов; база
  заданий фильтруется по обоим параметрам.
- **База заданий** — `src/data/tasks.json`, формат
  `{class, subject, type: "example"|"letter", question, answer, options}`.
  Пример пополняется вручную — просто добавляйте новые объекты в JSON.
- **UI** — счётчики рублей/самоцветов всегда в HUD сверху; родительский
  экран закрыт простым примером на сложение (не настоящий PIN, но
  недоступен для дошкольника) и показывает сумму, историю по дням и
  разбивку верных ответов по предметам.
- **Технически** — без рекламы, без трекинга/аналитики, без сетевых
  вызовов кроме загрузки JSON с локального сервера и CDN-скрипта Phaser.
  Прогресс хранится в `localStorage` браузера.

  сторы — код уже написан как обычный веб-проект, конфликтов с этим нет.
