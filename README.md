# Прыг-Скок — обучающий раннер (MVP)

Мобильная обучающая игра-раннер: персонаж бежит по кубикам, маленькие — просто
тапом, каждый N-й кубик — задание (математика / русский язык). Правильный
ответ — +1 ₽, персонаж прыгает дальше. Веб (HTML + Phaser 3), без сервера,
без рекламы и трекинга, прогресс хранится локально в `localStorage`.

## Запуск

Нужен любой статический HTTP-сервер (для `fetch` базы заданий), просто
открыть `index.html` через `file://` не получится.

```bash
cd game
npx http-server -p 8080 .
# либо: python3 -m http.server 8080
```

Открыть `http://localhost:8080` в мобильном браузере (или в DevTools mobile
emulation).

**Важно:** сервис-воркер (см. ниже) требует "secure context" — это либо
`https`, либо `localhost`. Если открываете с телефона по IP компьютера в
локальной сети (`http://192.168.x.x:8080`), PWA-функции (офлайн, установка)
работать не будут — сама игра при этом будет работать нормально, просто без
установки на экран. Для полноценного теста с телефона либо задеплойте на
любой https-хостинг (Netlify/Vercel/GitHub Pages — статические файлы, ничего
собирать не нужно), либо прокиньте порт через `adb reverse`/туннель, чтобы
телефон видел `localhost`.

## Установка как приложение (PWA)

Игра — полноценный PWA: манифест (`manifest.webmanifest`) + сервис-воркер
(`sw.js`), который кеширует всё необходимое при первом заходе и дальше
работает офлайн (проверено: после первой загрузки игра целиком, включая
задания, открывается в режиме "Offline" в DevTools).

- **Android (Chrome)** — при заходе на https-адрес появится баннер/пункт меню
  «Установить приложение» / «Добавить на главный экран». Иконка и имя
  («Прыг-Скок») берутся из манифеста, режим — `standalone` (без адресной
  строки браузера).
- **iOS (Safari)** — манифест Safari не читает для установки, поэтому иконка
  и мета-теги (`apple-touch-icon`, `apple-mobile-web-app-*`) прописаны прямо
  в `index.html` отдельно. Через меню «Поделиться» → «На экран “Домой”»
  приложение установится с той же иконкой и тоже откроется без адресной
  строки.

Иконки лежат в `assets/icons/` (192/512/512-maskable/apple-touch-icon),
исходники — SVG-разметка в `assets/icon-source.html` и
`assets/icon-maskable-source.html`, если понадобится перерисовать.

Чтобы обновление докатилось до уже установленных у пользователей копий,
достаточно поднять `CACHE_VERSION` в начале `sw.js` — старый кеш будет
удалён при следующей активации воркера.

## Структура

```
game/
  index.html          экраны (настройки/игра/статистика/родители) — чистый DOM
  data/tasks.json      база заданий
  src/
    styles.css
    storage.js         localStorage: прогресс, история, настройки
    tasks.js            загрузка базы + случайная выдача без повторов в сессии
    game.js              Phaser-сцена: бег, кубики, прыжки
    ui.js                 навигация по экранам, модалка задания, статистика, родительский экран
```

## База заданий

`data/tasks.json` — массив объектов:

```json
{ "class": 4, "subject": "math", "type": "example",
  "question": "358 + 246 = ?", "answer": "604",
  "options": ["604", "594", "614", "504"] }
```

Чтобы добавить новый предмет — просто добавь записи с новым `subject` и
подпиши его в `SUBJECT_LABELS` (`src/tasks.js`). UI отрисовывает вопрос и
варианты ответа универсально для любого `type`, специального кода под тип не
требуется, если новый тип тоже multiple-choice.

Сейчас в базе классы 4–5 (по данным из `tasks_4_5.json`); экран настроек сам
подхватывает список классов/предметов из файла, так что добавление классов
1–3 не требует правок кода — только новых записей в JSON.

## Геймплей

- Персонаж бежит автоматически, кубики скроллятся навстречу.
- Каждый 4-й кубик (`BIG_CUBE_INTERVAL` в `game.js`) — с заданием: бег
  останавливается, показывается модалка с вопросом и вариантами ответа.
- Верно → +1 ₽, персонаж перепрыгивает кубик, бег продолжается.
- Неверно → одна повторная попытка; если снова неверно — кнопка
  "Пропустить" (без штрафа деньгами, просто идёт дальше).

## Хранение данных

Всё — в `localStorage` (`jumpLearnGame.v1`): настройки, общая сумма,
разбивка по предметам, полная история ответов. Родительская панель
позволяет посмотреть сумму, экспортировать историю в JSON-файл или сбросить
прогресс. Доступ к ней закрыт простым математическим примером (не пароль —
не нужно ничего запоминать взрослому, но ребёнку сложно пройти).

## Дальше (не входит в MVP)

- Экран выбора нескольких классов одновременно уже поддержан (мультивыбор),
  но в задании явно просили один предмет для MVP — оба предмета уже
  доступны и протестированы, можно просто их не выключать.
- PWA-манифест + service worker для полного оффлайн-режима и установки как
  приложение.
- Больше типов заданий (например, свободный ввод текста вместо выбора из
  вариантов) — потребует лишь новой ветки рендеринга в `ui.js`.
