# Конструктор разводки водоснабжения

Однофайловый веб-инструмент (HTML/CSS/JS, без зависимостей) для проектирования узла ввода водоснабжения: коллекторы, арматура, трубы и потребители на SVG-схеме, с автоматическим расчётом площади, длины труб и спецификации оборудования.

Открыть: `index.html` в любом браузере.

## Возможности

- Палитра элементов: ввод ХВС/ГВС, коллекторы, тройники/отводы, арматура (краны, фильтры, счётчик, сгон, соединитель, датчик гидроудара, аварийный кран), водонагреватель, потребители.
- Трассировка труб кликами по стене с произвольными поворотами; диаметр трубы задаётся в мм или дюймах.
- Поворот выбранного элемента на 90°: кнопка «⟲ Повернуть», клавиша `R` или `Пробел`.
- Спецификация оборудования (Спецификация → CSV): автоматически считает количество и типоразмер каждой единицы арматуры/фитинга — размер берётся из диаметра фактически подключённой к нему трубы, — а также метраж труб по диаметрам и недостающие соединители-евроконусы под коллектор.
- Опциональное ограничение по месту (габариты ниши/шкафа) с индикацией, помещается ли узел.
- Сохранение/загрузка схемы в localStorage браузера.
