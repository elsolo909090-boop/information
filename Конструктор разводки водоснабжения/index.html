ВК-01

Конструктор разводки водоснабжения

× см
Выберите элемент на схеме, чтобы изменить его параметры — или добавьте новый из панели слева.

Начните с «Ввод ХВС/ГВС» — это труба из стояка. Дальше: счётчик → кран → коллектор → арматура → потребитель.

Горячие клавиши: R / Пробел — повернуть, Delete — удалить, Ctrl+C / Ctrl+V — скопировать / вставить, Ctrl+Z — отменить, Ctrl+колесо мыши — масштаб.

Условные обозначения
Труба ГВС (горячая)
Труба ХВС (холодная)
Труба без источника
Занимаемая площадь узла: — Габариты: — Элементов: 0 Кликните по палубе слева, чтобы добавить элемент на стену.
